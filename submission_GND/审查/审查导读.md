# 审查导读（Reviewer Guide）

本文件夹为投稿前审查提供完整证据链：补充材料、原始结果表、分析代码、投稿文件。
以下按审查中最受关注的五个问题给出文件定位与说明。

---

## 问题 1：WEBS 的完整计算流程

| 内容 | 文件 |
|------|------|
| WEBS 独立实现（单细胞 UCell 差值 / bulk 均值差值 / 蛋白均值差值） | `03_代码/webs.R` |
| 分组阈值 | 四分位法：LLS = 下 25%，LDTS = 中间 50%，LHS = 上 25%（Methods 2.2；所有队列一致） |
| 样本级 WEBS 值（CPTAC 99 例） | `02_结果表/cptac_webs.csv` |
| 蛋白层面 WEBS 构成（10 writer + 16 eraser 蛋白，TMT 检测所限，无插补） | 补充表 `S_protein_WEBS` |

说明：单细胞用 UCell（maxRank = 1500），bulk 用 log2 均值差值，蛋白用 TMT 丰度均值差值；三个层面的基因集定义一致（6 writers / 8 erasers），蛋白层面因 TMT 检测覆盖不同而为 10/16。

## 问题 2：六基因预后模型

| 内容 | 文件 |
|------|------|
| 六个基因及锁定系数 | `02_结果表/sixgene_coefficients.csv` |
| 各队列验证（HR、95% CI、Cox p、KM p） | `02_结果表/sixgene_validation_summary.csv` |
| 全队列性能（per-SD HR、C-index、时间依赖 AUC） | `02_结果表/signature_performance_full.txt` |
| LASSO 训练代码（glmnet，10-fold CV，lambda.min，29 个预设候选基因） | `03_代码/09_sixgene_signature.R` |
| Bootstrap 稳定性（1,000 次） | `03_代码/15_bootstrap_stability.R` + `02_结果表/bootstrap_selection_frequency.csv` |

说明：候选基因池预先定义（29 个基因），未在折内重新筛选；未做嵌套 CV（已在 Methods 中声明为局限）。六个基因在所有图、表、模型中完全一致：HIF1A, SIRT2, MMP2, ITGA5, HDAC1, SPP1。

## 问题 3：CPTAC 蛋白质组 107/111 与 107/109 的分母差异

| 数字 | 含义 | 文件 |
|------|------|------|
| 107/111 | 111 个通过检测过滤的剪接体蛋白中，107 个在 LHS vs LLS 差异分析中上调 | `02_结果表/cptac_spliceosome_proteins.csv` + `cptac_limma_results.csv` |
| 107/109 | 109 个同时具有 mRNA 和蛋白定量的剪接体基因中，107 个蛋白层相关性强于 mRNA 层 | `02_结果表/uncoupling_per_gene.csv` |
| PTM 母蛋白丰度校正 | 校正前后 OR（乙酰化 7.36→2.29；磷酸化 3.26→2.95） | `02_结果表/ptm_abundance_correction.txt` + `03_代码/57_ptm_abundance_correction.R` |

说明：111（蛋白差异分析可测）与 109（双层可配对）的差异来自 TMT/RNA-seq 交集基因数不同，非计算错误。

## 问题 4：GLASS 纵向分析的患者重叠处理

| 分析 | 样本量 | 患者数 | 文件 |
|------|--------|--------|------|
| 原发-复发 WEBS 配对比较 | 179 对 | 148 患者 | `02_结果表/glass_longitudinal_pairs.csv` |
| 原发 WEBS vs 复发间隔 | 213 条记录 | 173 患者 | `02_结果表/glass_recurrence_interval.csv` |
| 首配对敏感性分析（每患者仅一对） | 173 | 173 | `02_结果表/glass_firstpair_sensitivity.txt` |

说明：补充表 `S_glass_design` 列出了四项分析各自的纳入条件与分析单位；首配对分析结果（ρ=0.31, p=2.8e-05）与全记录分析（ρ=0.33, p=1.1e-06）一致。

## 问题 5：药物分析的证据分级

| 证据类型 | 性质 | 文件 |
|---------|------|------|
| DepMap CRISPR | 基因依赖性（Chronos 相关） | `02_结果表/depmap_webs_dependency.csv` |
| GDSC2 | 单药敏感性关联（ln IC50 相关） | `02_结果表/gdsc2_drug_webs_corr.csv` |
| Bliss 组合 | 预测协同（计算推演，非实测） | `02_结果表/gdsc2_combination.csv` |
| CMap | 表达扰动相似性 | `02_结果表/cmap_candidates.csv` |
| 分子对接 | 计算结构证据（结合能） | 补充表 `S_docking` |

说明：四者在正文中明确区分，Table 2（补充表 `S_Table2_targets`）以 "Tier = 实验验证优先级" 而非 "已验证靶点" 表述；SF3B1/SRSF1 的 DepMap 结果为 nominal 显著（未过 FDR），已如实标注。
